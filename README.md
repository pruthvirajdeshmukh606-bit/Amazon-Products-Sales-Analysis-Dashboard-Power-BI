Amazon Products Sales Analysis Dashboard
📊 Project Overview

This project focuses on analyzing Amazon product sales data and creating an interactive Power BI dashboard to understand sales performance, product categories, sales trends, and customer reviews.

The dashboard helps transform raw sales data into meaningful insights through KPIs, charts, tables, and interactive filters.

🎯 Project Objectives
Analyze overall sales performance
Track YTD Sales and QTD Sales
Analyze monthly and weekly sales trends
Identify top-performing products
Compare sales across product categories
Analyze products based on customer reviews
Build an interactive Power BI dashboard
